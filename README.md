# Донер на Абая — сайт

Сайт филиала «Донер на Абая», Астана, ул. Едил, 26. На сайте меню, корзина и заказ через WhatsApp. Есть две версии: русская (`/ru`) и казахская (`/kz`).

Технологии: Next.js 16 (App Router, статическая генерация), React 19, TypeScript, Tailwind CSS 4, Zod, Lucide.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить значения
npm run dev                  # http://localhost:3000 → /ru
npm run build && npm start   # продакшен-сборка
npm run lint
```

### Как поменять цену

1. Откройте `src/data/menu.ts`.
2. Найдите блюдо по `id`, например `doner-chicken`.
3. Цена указана в поле `price` каждого варианта. Для донеров варианты задаются строкой `donerSizes(цена S, цена M)`.
4. Сохраните файл и задеплойте сайт. Цена обновится в меню, в корзине, в сообщении WhatsApp и в разметке Schema.org.

### Как поменять номер WhatsApp

В `src/config/site.ts` есть поле `whatsapp`. Пишите только цифры с кодом страны, без `+`: `77470308969`. Номер для звонков задаётся отдельно, в полях `phone` и `phoneDisplay`.

### Как добавить блюдо

Скопируйте любой объект в массиве `products` в `src/data/menu.ts` и задайте уникальный `id`. Фото положите в `src/assets/menu/`: квадратное, WebP, около 1000 px. Добавьте его через `import` в начале файла.

## Как работает заказ

1. Гость добавляет блюда в корзину. Корзина хранится в `localStorage` и не пропадает после перезагрузки страницы.
2. Гость заполняет форму: имя, телефон, самовывоз или доставка, адрес (только для доставки), комментарий. Все поля проверяются через Zod. Телефон должен быть казахстанским мобильным номером. Из текста удаляются управляющие символы и `<>`.
3. Открывается `wa.me/<номер>?text=...` с готовым текстом заказа. Гость сам нажимает «Отправить».
4. **Заказ считается принятым, только когда ресторан ответит в WhatsApp.** Сайт так и пишет гостю. Своего сервера, автоматической доставки или онлайн-оплаты у сайта нет.

## Аналитика

GA4 и Яндекс Метрика подключаются только при двух условиях:
- в `.env` указаны `NEXT_PUBLIC_GA4_ID` и/или `NEXT_PUBLIC_YM_ID`;
- посетитель нажал «Согласен» в баннере.

Пока ID нет, скрипты счётчиков не загружаются и баннер не показывается.

Сайт отправляет события `menu_view`, `product_click`, `add_to_cart`, `remove_from_cart`, `begin_checkout`, `order_submit`, `whatsapp_click`, `phone_click` и `map_click`. `page_view` счётчики отправляют сами. В Метрике события приходят как цели (`reachGoal`).

## SEO

- Для каждого языка заданы title, description и canonical. Есть `hreflang` (ru, kk, x-default), а также теги Open Graph и Twitter Card.
- `/sitemap.xml` и `/robots.txt` генерируются автоматически.
- В JSON-LD размечены `Restaurant`, `PostalAddress`, `GeoCoordinates`, `OpeningHoursSpecification` и `Menu → MenuSection → MenuItem → Offer`.
- `aggregateRating` в разметку **намеренно не добавлен**. Google не показывает звёзды для оценок, которые бизнес публикует о себе сам, и считает такую разметку нарушением правил.
- Для Search Console и Яндекс Вебмастера заполните `NEXT_PUBLIC_GSC_VERIFICATION` и `NEXT_PUBLIC_YANDEX_VERIFICATION`. Потом отправьте `https://<домен>/sitemap.xml` в обе системы.

## Деплой на Vercel

1. Загрузите проект в GitHub.
2. На vercel.com: **Add New → Project**, выберите репозиторий. Фреймворк определится сам (Next.js).
3. В **Settings → Environment Variables** добавьте переменные из `.env.example`. Обязательно укажите `NEXT_PUBLIC_SITE_URL`.
4. Нажмите **Deploy**. Свой домен подключается в **Settings → Domains**. После этого обновите `NEXT_PUBLIC_SITE_URL` и сделайте Redeploy.

## Структура

```
src/
  app/[lang]/        layout (метаданные, шрифты, JSON-LD) и page (секции)
  app/sitemap.ts     robots.ts, icon.svg
  sections/          блоки страницы (hero, меню, отзывы, адрес…)
  components/        корзина, оформление, шапка, галерея, аналитика
  config/site.ts     бизнес-данные
  data/              меню и отзывы
  i18n/              словари RU / KZ
  lib/               заказ и WhatsApp, валидация, аналитика, форматирование
  assets/menu/       фото блюд (WebP)
```
